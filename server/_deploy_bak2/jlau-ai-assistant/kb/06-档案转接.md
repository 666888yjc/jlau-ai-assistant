# 档案与党团关系转接

## 学籍档案
- 转交方式按考生所在省份招生考试机构规定执行。
- 新生自带档案的：报到时交给所在学院学生工作办公室。
- 由招生考试机构或中学统一邮寄的：入学后统一转给学院学工办。
- 档案不得私自拆启，拆封不予接收。
- 来源：历年入学须知、2020 级本科新生入学报到须知。

## 党组织关系
- 吉林省内党员：通过「全国党员管理信息系统」线上转接，不接收纸质介绍信；去向填「中共吉林农业大学 XX 学院委员会」。
- 吉林省外党员：线上系统转接 + 县级以上党委开具纸质介绍信（抬头：中共吉林省委教育工委组织部 / 中共吉林农业大学委员会），报到时交学院辅导员。
- 来源：历年党团关系转接须知、2026 级研究生须知。

## 团组织关系
- 线下：毕业学校开具团组织关系介绍信，抬头统一填「共青团吉林农业大学委员会」，入学后交学院团委。
- 线上：在「智慧团建」系统发起转接；开学核查团籍档案后由学院团委统一接收，开学前暂不处理。
- 来源：历年入学须知、校团委相关说明。

## 温馨提示
- 党员/团员材料务必随档案或单独妥善保管，报到时按学院要求提交。
- 档案接收（研究生）：党委研究生工作部教育管理科，电话 0431-84533149 / 84533305（本科新生档案交学院学工办）。
