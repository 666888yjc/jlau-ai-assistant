# 学费与缴费

## 学费标准（2026 年本科，部分专业示例）
- 农学 / 园艺 / 植物保护 / 种子科学与工程：5500 元/年
- 动物科学 / 动物医学 / 水产养殖学 / 园林：5500 元/年
- 计算机科学与技术 / 食品科学与工程 / 制药工程 / 风景园林 / 新能源科学与工程：5940 元/年
- 环境科学 / 数据科学与大数据技术 / 农业智能装备工程 / 酿酒工程：5400 元/年
- 中药学 / 中药资源与开发：6160 元/年
- 工商管理 / 社会学 / 家政学：5280 元/年
- 金融学 / 市场营销 / 思想政治教育 / 旅游管理：4800 元/年
- 传播学：6800 元/年
- 中外合作办学：生物技术（中意）25000 元/年、动物科学（中美）26000 元/年
- 完整专业学费见《吉林农业大学 2026 年招生章程》及通知书附件。
- 来源：zhaosheng.jlau.edu.cn 2026 招生章程、hfplg.com。

## 住宿费
- 根据住宿条件不同，约 1000–1200 元/学年（不含在学费内）。
- 来源：hfplg.com 学费明细。

## 缴费方式
- 手机端：微信关注「吉林农业大学计划财务处」公众号 → 服务指南 → 缴费攻略，扫码缴费。
- 电脑端：登录 http://cwgl.jlau.edu.cn/xysf/ 。
- 登录方式：用户名=身份证号，密码=身份证后六位。
- 学校统一收取学费并开具财政票据，未授权任何机构或个人代收。
- 警惕非官方缴费渠道，谨防诈骗。
- 来源：继续教育学院缴费说明（jxjyxy.jlau.edu.cn，可参照流程）、计划财务处公众号。

## 资助与绿色通道
- 高校学生资助政策：国家奖学金、国家励志奖学金、国家助学金、国家助学贷款、勤工助学、「绿色通道」、学费减免、临时困难补助等。
- 生源地信用助学贷款：入学前到户籍所在县（市、区）学生资助管理机构申请办理。
- 入学后家庭经济困难学生可向学校申请资助。
- 来源：zhaosheng.jlau.edu.cn 2026 招生章程「学生资助政策」。

## 温馨提示
- 缴费时间、金额以通知书及计划财务处最新通知为准。
- 勿通过非官方链接或陌生人代缴费。
