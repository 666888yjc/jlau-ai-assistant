# 国家奖助学金一览（要点）

## 1. 奖励标准速查
| 项目 | 金额 | 说明 |
|---|---|---|
| 国家奖学金 | 8000 元/人·年 | 二年级以上特别优秀学生 |
| 国家励志奖学金 | 5000 元/人·年 | 二年级以上品学兼优的家庭经济困难学生 |
| 吉林省政府奖学金 | 4000 元/人·年 | 条件同国家奖学金 |
| 国家助学金 | 三档 4300 / 3300 / 2300 元/人·年 | 家庭经济困难学生；退役士兵学生全部享受，标准 3300 元/人·年 |
- 来源：吉林农业大学国家奖学金、国家励志奖学金、吉林省政府奖学金、国家助学金管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2044.htm）

## 2. 申请条件要点
- **国家奖学金**：二年级以上；成绩与综合素质评价排名均在前 10% 且无不及格科目；未进前 10% 但达前 30% 且在道德风尚/学术研究/学科竞赛/创新发明/体育/艺术展演等某一方面表现非常突出者可申请（需证明材料）。
- **国家励志奖学金**：二年级以上；当学年平均学分绩 80 分以上且无不及格科目；德育评价及第二课堂成绩合格；原则上通过当学年家庭经济困难认定。
- **吉林省政府奖学金**：条件同国家奖学金。
- **国家助学金**：家庭经济困难学生；申请学期内未受纪律处分或处分已解除；原则上通过当学年困难认定。学校认定家庭经济特别困难学生资助标准为 4300 元/年。
- 同一学年内，国家奖学金、国家励志奖学金、省政府奖学金不能兼得；但可同时申请国家助学金。
- 来源：吉林农业大学国家奖学金、国家励志奖学金、吉林省政府奖学金、国家助学金管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2044.htm）

## 3. 评选流程（学院评审 → 公示 → 上报）
1. 本人提出书面申请；
2. 班级（年级）民主评议，确定参评资格（辅导员参加）；
3. 学院学生工作办公室初审材料，按名额指标依据综合素质评价成绩排序评选（国家助学金按困难程度评选，同等困难取综合素质评价较高者）；
4. 学院评审领导小组等额评选，确定拟获名单，**学院内公示 3 个工作日**；
5. 报学校审批，学校评审领导小组确定名单，**全校公示 5 个工作日**无异议后上报省资助中心审批；
6. 资金划拨到校后由学生工作部（处）协调计划财务处及时足额发放。
- 来源：吉林农业大学国家奖学金、国家励志奖学金、吉林省政府奖学金、国家助学金管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2044.htm）

## 4. 奖助学金中止/追回
- 有下列情形之一取消资格并追回已发资金：违反国家法律法规、受纪律处分、虚报家庭经济情况、复核不符合条件、不正确使用受助资金（高消费/铺张浪费）等。
- 休学/保留学籍期间暂停发放国家助学金，恢复学籍后再发；超过基本修业年限不再享受。
- 来源：吉林农业大学国家奖学金、国家励志奖学金、吉林省政府奖学金、国家助学金管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2044.htm）

## 5. 校长奖学金暨十佳大学生（学校最高奖）
- 金额：**每人 1 万元/年**；在校期间不得重复获得。
- 对象：二年级以上全日制本科（含第二学士学位）学生。
- 名额：每学年评选一次，每次 10 名，**每年九月份**进行；符合条件者不足 10 人可少于名额。
- 条件：成绩与综合素质评价在专业前 30%，德育及第二课堂合格，无违纪；在理论学习/专业学习/社会实践/创新创业/文艺/体育/志愿服务/自强自立/文明礼仪/社会责任/国防志愿某一方面表现突出（某方面极为突出可适当放宽）。
- 流程：学生申报 → 学院公开评选会推荐（学院公示 3 个工作日）→ 学生工作部（处）复审并公开答辩（全校公示 5 个工作日）→ 评审委员会审批。
- 在校期间受纪律处分者撤销荣誉称号、追回证书及奖金。
- 来源：吉林农业大学校长奖学金暨十佳大学生评选办法（试行）（https://xxgk.jlau.edu.cn/info/1076/2089.htm）

> 以学校最新官方通知为准。
