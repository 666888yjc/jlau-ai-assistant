# 学费减免与勤工助学（要点）

## 1. 学费减免：适用对象
- 面向在校全日制本科学生中**家庭经济特别困难学生**；额度依据家庭实际情况，参考减半、全免等实施。
- 减免条件：被认定为家庭经济特别困难学生；德育评价及第二课堂成绩合格、申请学期内未受纪律处分或已解除；学习刻苦、诚实守信、成绩良好；生活俭朴；积极参加校内外勤工助学活动。
- **吉林省农科生"订单式"培养学生及其他不缴纳学费的学生不享受减免政策。**
- 来源：吉林农业大学学费减免实施办法（https://xxgk.jlau.edu.cn/info/1078/2038.htm）

## 2. 学费减免：程序
1. 本人向学院提交书面申请，填写《减免学费申请审批表》《家庭经济困难学生认定申请表》；
2. 班级（专业）民主评议并上报学院评审工作小组；
3. 学院评审小组审核、拟定推荐人选及减免额度；
4. 学院公示 3 个工作日 → 报学生工作部（处）；
5. 学生工作部（处）审核确定名单及额度，全校公示 5 个工作日 → 报学校批准。
- 减免后管理：须缴清应缴学费余额否则不予减免；享受减免后违纪的责令足额补交已减免学费；弄虚作假查实后补交并给予纪律处分；挥霍浪费追缴；主观原因退学须补交后方可办手续。
- 来源：吉林农业大学学费减免实施办法（https://xxgk.jlau.edu.cn/info/1078/2038.htm）

## 3. 勤工助学：岗位与报酬
- 学校统一组织管理；学生私自在校外兼职不属于本办法范围。
- 时间限制：每周原则上不超过 8 小时、每月不超过 40 小时；寒暑假可适当延长。
- 岗位分固定岗位与临时岗位：
  - **固定岗位**（持续一学期以上/寒暑假连续）：按月计酬，**每月 300 元/人**；
  - **临时岗位**（一次或几次即完成）：按小时计酬，**不低于每小时 12 元/人**，临时岗位申请至少于用工前 5 天提出。
- 岗位设置以教学助理、科研助理、行政管理助理和公共服务为主；不得安排有毒有害危险作业、不得占用上课考试实习时间、不得替代教职员工本职工作。
- 来源：吉林农业大学学生勤工助学管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2037.htm）

## 4. 勤工助学：申请条件与流程
- 申请条件：思想品德/综合素质测评合格；申请学期内未受纪律处分或已解除；上一学期不及格科目不超过 2 科；生活勤俭。
- 流程：学生工作部（处）公布岗位 → 学生填写《勤工助学申请表》→ 辅导员初审 → 学生工作部（处）资助管理中心审批备案 → 学生工作部（处）推荐、用工单位同意聘用并签订《学生勤工助学协议》→ 上岗。
- 优先安排：原则上优先考虑经学校认定的家庭经济困难学生；少数民族学生尊重其风俗习惯。
- 取消资格情形：私自上岗、擅自不到岗、拒不服从安排、当月考核不合格、工作期间不及格科目达 3 门（含）以上、受到纪律处分。
- 校外勤工助学须由学校授权三方（学校/用人单位/学生）签订协议后方可开展。
- 来源：吉林农业大学学生勤工助学管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2037.htm）

## 5. 联系渠道
- 勤工助学与学费减免日常管理：**学生工作部（处）资助管理中心**（负责岗位审批、安排、报酬发放、审核减免等）；各学院学生工作办公室受理学生申请。
- 来源：吉林农业大学学费减免实施办法（https://xxgk.jlau.edu.cn/info/1078/2038.htm）、吉林农业大学学生勤工助学管理暂行办法（https://xxgk.jlau.edu.cn/info/1078/2037.htm）

> 以学校最新官方通知为准。
