# 军训安排

## 时间
- 一般为开学后不久进行，时长约两周（半个月）。
- 历年参考：2023 级为 9月8日–26日；2025 级为 10月13日–26日。具体以当年通知为准。
- 来源：林学与草学学院新生入学教育（lcxy.jlau.edu.cn）、gaokao.com 2025 开学时间。

## 内容
- 队列操练、内务整理（叠「豆腐块」）、军事理论学习、学唱红歌/校歌（《我是骄傲的大地之子》）。
- 强度总体不大，以基本科目为主；吉林夏秋气候相对干爽，体感较易适应。
- 来源：学生工作处军训感悟（xsc.jlau.edu.cn）、college.gaokao.com 生活环境。

## 服装与用品
- 军训期间需做到统一化；床上用品在新生报到时统一购买。
- 军训服装具体要求以通知书或学院通知为准。
- 来源：校团委新生秘籍（tuanwei.jlau.edu.cn）。

## 温馨提示
- 军训是大学第一课，注意补水、防晒，身体不适及时报告教官或辅导员。
- 因身体原因无法参训，按学校规定办理请假/观摩手续。
