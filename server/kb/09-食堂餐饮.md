# 食堂与餐饮

## 食堂分布
- 学校主要有多个学生食堂，常用称呼：
  - 三食堂（鸿之桐）
  - 四食堂（鸿之泽）
  - 五食堂（鸿之磐）
- 另有说法全校共五个食堂，一、二食堂亦在列；具体以校内导引为准。
- 来源：校团委新生秘籍、college.gaokao.com 生活环境。

## 餐饮特色
- 菜系齐全，价格亲民；就餐可免费喝汤。
- 三食堂二楼、四食堂二楼有面食；四食堂三楼有小火锅（多种锅底、自选蘸料）。
- 早饭有豆浆、包子、馅饼等。
- 来源：校团委新生秘籍。

## 档口级评分指南（强烈推荐）
- **三食堂、四食堂、五食堂各楼层档口**的 5 星评分 + 代表菜品 + 价格 + 点评，见独立文档「**32-食堂美食评分指南**」篇（基于《吉农美食篇·农大肴馔集锦 2024》整理）。
- 快速结论：三食堂一楼风味饭菜物美价廉、四食堂二楼吉祥馄饨与小小米线口碑最佳、五食堂二楼麻辣烫被评"最好吃"。

## 支付方式
- 食堂支持校园卡（实体卡/虚拟卡扫码）消费，详见「校园卡一卡通」篇。
- 来源：校团委新生秘籍、help.jlau.edu.cn。

## 温馨提示
- 饭点高峰较拥挤，建议错峰。
- 校内另有「浓渡」咖啡厅等休闲点位。
