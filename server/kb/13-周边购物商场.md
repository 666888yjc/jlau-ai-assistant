# 校内与周边购物指南

## 1. 校内（最方便）
- **大学生「一站式」购物中心**：位于学生生活区中心、紧邻食堂。内含**超市、打印社、水果店、电子产品维修店、衣物店、生活用品店、眼镜店、饮品店**，覆盖基本生活需求，定价合理、性价比高。
- **吉林农业大学百货商店（院内）**：经营日用百货、服装、副食品等（历史网点，部分柜台租赁中）。
- **学生手册实战**：校内有**美甲店、水果店、超市、剪发店、衣服店、洗衣店**等，生活服务很齐全；日常用品学校里有地方买，开学不必从家带。
- 来源：sizhengwang 吉农一站式生活驿站报道（2025-04-30）、新生手册（学生视角）。

## 2. 周边商场（步行/单车可达，约 1–1.5km）
- **迅驰广场**（博学路 1555 号，距校约 1km）：净月大学城核心商圈，含沃尔玛购物广场、必胜客及数十家餐饮奶茶，学生最常去。
- **农大购物中心**（新城大街 2888 号，约 1.1km）、**嘉年华广场**（农大北侧，约 1.3km）、**诺睿德广场**（新城大街与天富路交汇，约 1.2km）、**魔力 PARK**（新城大街 4126 号，约 1km）。
- 来源：360 地图 POI、腾讯地图。

## 3. 买衣服/鞋包
- 校内衣物店（一站式购物中心内）满足基础款。
- 迅驰广场品牌店、市区商场（摩天活力城、赛特奥莱等，距校 3–4km，可乘公交/轻轨）。
- 网购：校内取快递方便（见「快递物流驿站」篇），衣物多网购到校自提最省。

## 4. 日用品采购
- 日常：校内超市 + 一站式购物中心。
- 囤货/大促：迅驰广场沃尔玛、新天地超市（农大北路）、吉优客超市。
