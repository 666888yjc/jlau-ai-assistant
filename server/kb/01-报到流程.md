# 新生报到流程（本科）

## 1. 报到时间
- 以《录取通知书》上印制的报到日期为准，请勿提前或逾期。
- 历年参考：2025级为 9月14日（开学典礼 9月15日）；2023级为 9月2日。每年可能调整，务必以通知书为准。
- 学生手册经验：开学一般九月份，去年（学长学姐级）为 9.2 报到，今年有说法称 10.9 报到——**属非官方说法，最终以《录取通知书》为准**，通知书上会写明报到日期。
- 因故不能按期报到：须提前向录取学院学生工作办公室（学工办）书面请假；未请假或请假逾期者，除不可抗力外，视为放弃入学资格。
- 来源：吉林农业大学招生网入学须知（haojiao.net 2025-07-17 整理）、学籍管理办法（xxgk.jlau.edu.cn）、新生手册（学生视角）。

## 2. 报到地点
- 历年设在「中心教学楼前 / 崇智广场」各学院设立的新生报到处（不同广场对应不同学院群）。
- 具体你的学院在哪个广场、哪个点位，以通知书或辅导员通知为准。
- 来源：校团委新生攻略（tuanwei.jlau.edu.cn/a/zhaoshengjiuye/1003）、历年入学须知。

## 3. 接站服务
- 学校在长春站（北出口）设新生接站点，统一安排免费乘车抵校（历年接站时间约 6:00–21:00）。
- 外地新生如交通不便，可提前 1–2 天到校先入宿，无需校外住店。
- 来源：applysquare 报到流程经验帖、历年入学须知。

## 4. 报到须携带材料（清单）
1. 《录取通知书》原件
2. 高考准考证
3. 身份证原件
4. 近期免冠小2寸彩色照片 10 张（报到填表用）——学生手册提示：大部分要求**小二寸蓝底**照片，最好留**红、蓝、白底电子版**备用（开学后填表、办证常用）
5. 档案（自带或邮寄，见「档案转接」篇）
6. 党/团组织关系材料（见「档案转接」篇中的党团关系部分）
7. 户口迁移证（仅自愿迁移户口的同学，见「户口迁移」篇）
- 来源：历年入学须知（haojiao.net、555edu.com）、学籍管理办法、新生手册（学生视角）。

## 5. 开学必备（行李建议，学生手册实战版）
- **衣服**：夏季、冬季衣服都带一点；长春十月底**可能下雪**，羽绒服/厚外套可先寄或到校后添置（详见「长春气候与四季穿衣」篇）。
- **日用品**：校内商店有卖，**不必从家带**（详见「周边购物商场」篇）。
- **被子/床上用品**：军训期间学校要求**统一**，在学校指定地方购买；后续可自行更换。
- **照片**：大部分要求小二寸蓝底，最好保留红、蓝、白底电子版。
- **其他**：录取通知书、身份证、准考证等报到材料（见第 4 节清单）。
- 来源：新生手册（学生视角，2026-08 提供）。

## 6. 报到当天流程
1. 持《录取通知书》到校 → 找到本学院报到处。
2. 排队注册，上交所带档案，在信息核对单上签名确认。
3. 领取校园卡、宿舍区分配信息等。
4. 学院志愿者带至寝室，凭证件领取寝室钥匙。
5. 床上用品在新生报到时统一购买（军训期间需统一）。
- 来源：applysquare 报到流程经验帖、校团委新生秘籍（tuanwei.jlau.edu.cn/a/zhaoshengxinxi/1017）。

## 7. 温馨提示
- 新生可凭录取通知书购买一次半价火车票。
- 寝室安排由所在学院负责，事宜请联系学院学工办。
- 报到现场人流较大，听从志愿者指引，注意保管证件财物。
- 招生咨询/请假电话：0431-84532980（招生就业工作处）。

## 8. 录取通知书查询（学生手册实战）
- 学校官网可查到录取通知书的 **EMS 邮编（邮件号）**。
- 下载「**中国邮政**」APP，凭 EMS 邮编查询录取通知书寄送进程。
- 学生手册提醒：不要急，通知书下来后里面都有详细介绍（报到、缴费、宿舍等），一切以通知书为准。
