# 家长住宿与周边宾馆

> 农大北门/复地嘉年华周边宾馆密集，步行即达校园，价格梯度清晰。

## 1. 经济型（人均 40–70）
- 慕尚宾馆（净月大学城店，约 40）、阳光宾馆（约 58）、长春隐言青年旅社（约 49）、立方米快捷酒店（约 66）、果果假日宾馆（约 61）、布拉格欧式宾馆（约 56）。

## 2. 中端/公寓（人均 100–150）
- 长春子齐精品酒店（近北门/人文学院，约 118，口碑好）、长春君桐快捷宾馆（迅驰广场，约 101）、长春奥仁酒店公寓（约 123）、北极豹电竞酒店（约 144）、长春 LOVEmax 电竞（约 144）。

## 3. 连锁舒适型（含早/健身，约 279 起）
- **全季酒店（净月新城大街店）**：自助早+健身+洗衣，近农博园/净月潭，口碑 4.8。
- **星程酒店（净月农业大学店）**：华住旗下，4.9 分，约 279 起，服务热情房间宽敞。
- **长春合和时尚宾馆**：农大复地嘉年华，性价比高、老板热情，口碑 4.8–4.9。

## 4. 小贴士
- 家长如自驾，选带免费停车的（全季/合和等）。
- 报到当天人流大，宾馆入住高峰在午后被接站新生占满，建议上午到店办理。
