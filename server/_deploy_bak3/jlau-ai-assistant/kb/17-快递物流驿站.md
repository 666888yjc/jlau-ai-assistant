# 快递物流与驿站

## 1. 收件地址（统一填这个）
> **吉林省长春市南关区新城大街 2888 号 吉林农业大学**
> 务必写清**姓名+电话+宿舍楼/学院**，方便驿站分拣。

## 2. 校内取件
- **「一站式」卡卡小屋智慧物流中心**：位于学生公寓区中心，早 8:00–晚 20:00，双站点覆盖，支持主流快递**寄件取件一码通**。凭短信定位→货架导航→身份码极速出库，取件效率较传统提升 50%。
- **菜鸟驿站**：农大北门东 50 米；卡卡小屋 2 号店（新城大街 2888）。
- **京东物流**：农大 B2 菜鸟驿站代收。
- 来源：sizhengwang 一站式驿站、city8、顺丰查询网。

## 3. 寄件
- 卡卡小屋、菜鸟驿站均可寄主流快递；毕业季/退换货常用。
- 大件可叫上门揽收（各快递小程序）。

## 4. 小贴士
- 新生季快递暴增，取件短信可能延迟，留意驿站公告栏。
- 贵重物品建议本人签收，错拿可凭身份码在驿站找回。
