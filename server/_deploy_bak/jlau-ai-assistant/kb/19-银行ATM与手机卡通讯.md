# 银行 ATM 与手机卡通讯

## 1. 校内 ATM
- **四食堂**：吉林农商银行、邮政储蓄 ATM。
- **五食堂**：中国农业银行 ATM。
- **北门外**：农业银行分行、邮政储蓄分行、工商银行 ATM（校门口网点更靠谱，食堂 ATM 偶发故障）。
- 来源：搜狗问答（校内 ATM 分布，2019 经验帖，仍具参考）。

## 2. 周边银行（北门/迅驰广场 1km 内）
- 农行农大北路支行（约 639m）、邮储农大营业所（约 699m）、吉林银行迅驰广场店、工行迅驰广场店、建行迅驰广场店、中行新城大街支行、中信迅驰广场支行。
- 来源：腾讯地图 POI。

## 3. 手机卡/宽带
- 校内北门一带有**移动、联通营业厅**（农大手机卖场设在联通营业厅内）；开学季三大运营商在校园设摊办卡，学生套餐优惠多。
- 建议：到校办一张长春本地卡（大流量学生套餐），家里异地卡可保留接验证码。
- 宿舍宽带：开学后按学校/运营商通知办理，勿轻信上门推销。
- 来源：qcc 农大手机卖场、校内经验。

## 4. 银行卡小贴士
- 录取通知书附「学子卡」用于学费代扣，务必激活并存足学费。
- 生活费可另开一张，异地存取有手续费，邮政绿卡/本地卡较合适。
