# 医疗与校医院指南

## 1. 校医院（首选，校内）
- **吉林农业大学医院**：地址新城大街 2888 号（校园北侧），**一级甲等公立医院**，电话 **0431-84532820**，1984 年建，职工 66 人，省医保定点。
- 门诊：内、外、妇、儿、中医、五官、口腔等科；设急诊室、检验科、放射科、药剂科。
- 承担全校学生日常医疗，感冒发烧、外伤处理、开药均可在校医院完成，方便便宜。
- 来源：99 健康网、doctor.healthr 吉农医院简介。

## 2. 周边医院（1–3km）
- **长春吉润净月医院**（新城大街 5000 号，吉大一院托管，约 1km）
- 吉林财经大学医院（约 2km）、中信社区卫生服务中心（约 2km）、仁惠医院（约 2km）、博硕街道社区卫生服务中心（约 2km）
- 来源：腾讯地图 POI、iecity。

## 3. 三甲/专科（较远，重病去这）
- **吉林大学中日联谊医院**（仙台大街 126 号，三甲，约 5.8km）：综合实力强，急诊首选。
- **长春中医药大学附属第三临床医院**（净月大街 1643 号，约 3km）。
- 妇产科/孕检：校医院妇科门诊，或长春市妇幼保健院（南关区，约 4km）。
- 来源：腾讯地图、39 健康网。

## 4. 就医提示
- 带校园卡/身份证；校医院门诊时间参考工作日常规，急诊室 24h 待命。
- 突发急症直接拨打 120，并联系辅导员/舍友陪同。
- 来源：校医院公开信息、39 健康网温馨提示。
