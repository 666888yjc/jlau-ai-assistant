# 宿舍与住宿

## 房型
- 宿舍多为六人间或八人间，部分楼栋有四人间；有上下铺结构，少数楼栋为上床下桌。
- 空调：多数楼栋无独立空调（不同来源说法不一，以录取通知书/后勤公告为准）。
- 卫浴：多数楼栋为公共浴室/公共卫浴，少数楼栋有独立卫生间。
- 来源：校团委新生秘籍、sushe.help 宿舍条件（数据更新 2026-06-29）。

## 楼内设施
- 每层楼配有饮水机、吹风机（微信支付，0.5 元/3 分钟）。
- 每栋宿舍楼一楼有洗衣房、晾衣房：洗衣机（微信或校园卡支付，甩干 1 元 / 快速洗 2 元 / 标准洗 3 元 / 大物洗 4 元）、刷鞋机。
- 直饮水：各楼宇直饮水机覆盖，校园卡刷卡取水（详见「校园卡一卡通」篇）。
- 来源：校团委新生秘籍。

## 管理
- 门禁时间约 22:30；部分楼栋夜间断电、限电约 300W（以楼栋管理规定为准）。
- 大一有晨跑/早晚自习要求（以学院为准）。
- 床上用品在新生报到时统一购买（军训期间统一化）。
- 宿舍分配由所在学院负责，事宜联系学院学工办。
- 来源：sushe.help、校团委新生秘籍。

## 洗澡
- 宿舍多为公共浴室，可通过「完美校园」APP/小程序预约洗澡（详见「校园卡一卡通」篇）。
- 来源：新版校园卡说明（help.jlau.edu.cn）。

## 温馨提示
- 报到当天学院志愿者会带新生到具体宿舍并领取钥匙。
- 宿舍物品丢失或报修，联系楼管或学院学工办。
