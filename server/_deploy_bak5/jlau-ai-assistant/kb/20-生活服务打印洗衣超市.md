# 生活服务：打印、洗衣、超市

## 1. 打印/复印
- 校内：**「一站式」购物中心内打印社**（作业、证件复印最方便）。
- 北门周边：东华打字复印照相（农大老区店，约 638m，08:00–19:00）、智汇图文广告（复地嘉年华，约 799m，07:00–23:00）、盛和一方图文（约 926m）。
- 大学城：文通快印（博学路大学城，约 1km）、学子图文快印（至 22:00）。
- 来源：腾讯地图 POI、BOSS 直聘。

## 2. 洗衣
- 宿舍楼内一般配**洗衣机**（部分用「完美校园」APP 预约，见「08-校园卡」篇）。
- **五服超市**（五食堂原锅炉房）提供**洗衣接活服务**；校内另有洗衣店。
- 来源：ganji 五服超市经营范围、校内经验。

## 3. 超市/日用品
- **五服超市**（校内五食堂原锅炉房）：食品、日用品、水果、文具、五金、烟草、复印照相，学生常用。
- 新天地超市（农大北路）、吉优客超市、晨星超市；一站式购物中心内设超市。
- 大件囤货去迅驰广场沃尔玛（见「13-周边购物」篇）。
- 来源：ganji、liepin、sizhengwang、360 地图。

## 4. 其他
- 眼镜店、电子产品维修店、水果店均集中在「一站式」购物中心，校内解决大部分需求。
