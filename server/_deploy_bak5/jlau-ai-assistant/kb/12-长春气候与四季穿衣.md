# 长春气候与四季穿衣指南

## 1. 气候总览
- 长春属**温带季风气候**，四季分明：**冬季漫长严寒、夏季短促温和、春秋宜人但风大温差大**。
- 全年平均气温约 4.6℃；1 月最冷（均温约 −15℃，极端曾达 −39.8℃），7 月最热（均温约 23℃，极端高温约 39.5℃）。
- 供暖期约 **11 月中旬至次年 4 月中旬**，室内温暖如春（甚至穿单衣），室外冰天雪地——「室内外两重天」是新生最需适应的点。
- 来源：吉林大学入学早知道（jlu.edu.cn）、jiusongjiankang 长春四季温度。

## 2. 各季穿衣建议
- **春季（3 月末–5 月末，均温 0–15℃）**：多风、昼夜温差大。长袖+薄外套/风衣，备口罩帽子护呼吸道；偶尔有春雨带伞。
- **夏季（6 月初–8 月末，均温 15–30℃）**：短袖短裤即可，但**早晚凉爽**需薄外套；午后雷阵雨多，随身带伞+防晒。比南方干爽，被誉为宜居季。
- **秋季（8 月末–10 月末，均温 15–0℃）**：初秋薄外套/针织，深秋毛衣+厚外套；干燥少雨。
- **冬季（10 月末–3 月末，均温 0–−25℃）**：**厚羽绒服、保暖内衣、防寒靴、手套、围巾、毛帽**必备；南方同学务必备好抗 −20℃ 装备。
- 来源：eastchinatrip 每月气候、zaibaike 长春四季穿衣、马蜂窝长春速览。

## 3. 新生报到季（8 月末–9 月）建议
- 报到正值夏末秋初：中午短袖、早晚长袖/薄外套。**报到带夏装+秋装即可**，冬装到校后就近购买（校内衣物店、迅驰广场品牌店均有）。
- 不必从家背厚冬装，减轻行李负担；长春买羽绒服方便且更适应当地。
- 来源：吉林大学入学早知道（新生穿衣建议）。

## 4. 其他提示
- 宿舍暖气足，室内可单衣；但去教室/图书馆注意楼道温差。
- 冬季路面易结冰，鞋底选防滑；长春冬季干燥，润肤露必备。
- 长春整体消费不 high，穿衣以实用保暖为主，无需盲目追求品牌。
