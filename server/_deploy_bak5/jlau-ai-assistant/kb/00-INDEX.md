- 知识库仅收录公开信息，不含身份证/银行卡/家庭住址等隐私字段（符合 SPEC AC-10）。
- 凡知识库无答案或低置信的问题（如某专业分数线、保研率、实时路况），助手按 AC-03 不编造，引导联系招生办 0431-84532980 或建议查官方/地图。
