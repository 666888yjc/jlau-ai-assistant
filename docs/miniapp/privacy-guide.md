# M-4 《用户隐私保护指引》要点 + 可粘贴文案

> 原则：**最小化收集**（PRD D-M6 / AC-M4.4）。本小程序无登录、无支付、无消息订阅，
> 仅通过 web-view 提供咨询信息服务，与 H5 既有 handoff 隐私过滤口径一致。

---

## 1. 配置入口

微信公众平台 → 小程序 → **设置 → 服务内容声明 → 用户隐私保护指引** → 按平台引导填写并提交。

> 微信对未配置隐私指引的小程序有弹窗拦截（「小程序需要获取你的同意…」类提示），
> 提审前必须配置完成。

---

## 2. 可粘贴文案（最小化收集声明）

### 2.1 收集信息类型（公众平台「用户隐私保护指引」表单）

| 项 | 填写建议 |
|---|---|
| 收集的信息 | **不主动收集**（不勾选「手机号」「位置」「相册」等权限类收集项） |
| 用途说明 | 本小程序仅通过内置网页（web-view）提供报到流程、材料清单等咨询信息服务；对话内容仅用于答疑质量改进，不用于其他用途 |
| 第三方 | web-view 加载的 H5 页面（`https://<CUSTOM_DOMAIN>`）由运营方自建部署，无第三方 SDK 收集 |

### 2.2 隐私政策正文（可粘贴）

> **吉小农报到助手隐私说明**
>
> 1. 本小程序为「报到答疑」咨询信息服务工具，通过 web-view 展示内置网页，不提供账号登录、支付、消息订阅等功能。
> 2. 我们**不主动收集**您的手机号、证件号、位置等个人信息。您在小程序内输入的问题内容仅用于向您提供答疑服务，
>    并仅用于答疑质量改进；系统已对涉及手机号/证件号等强隐私字段进行过滤。
> 3. 小程序页面内容由自有域名 `https://<CUSTOM_DOMAIN>` 提供，不接入第三方广告或统计 SDK。
> 4. 我们不会将您的信息用于任何与本服务无关的用途，也不会向无关第三方提供。
> 5. 如您对隐私保护有疑问，可通过小程序内「转人工」渠道联系我们。

---

## 3. 与 H5 口径一致性（AC-M4.4）

- H5 既有 handoff 隐私过滤已过滤手机号/证件号等强隐私字段——本指引声明口径与之一致；
- **不新增任何信息采集**（PRD Q-M7）：小程序壳零埋点、零 SDK、零登录授权；
- 若将来接入统计（M-7），仅使用微信公众平台后台自带数据（访问人数/次数），无需额外声明。

---

## 4. 常见驳回点

| 风险 | 规避 |
|---|---|
| 隐私指引未配置 | 提审前在公众平台完成「用户隐私保护指引」配置 |
| 文案含「收集承诺」 | 使用本文件 §2.2 文案，不含收集/存储承诺 |
| 与 H5 口径不一致 | 两边统一「最小化收集」口径，不写手机号/证件号等强隐私收集 |
