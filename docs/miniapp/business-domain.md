# M-3 微信公众平台「业务域名」配置步骤清单

> 目标：在微信公众平台把 `<CUSTOM_DOMAIN>` 加入小程序**业务域名**，使 web-view 加载该域名页面时
> 不再出现「非业务域名」拦截提示（AC-M3.3）。
>
> 前置：① 域名已备案；② 已按 `docs/miniapp/domain-binding.md` 完成 CloudBase 网关层绑定（HTTPS 证书有效）；
> ③ 拥有小程序管理员/开发者权限可登录微信公众平台。

---

## 1. 为什么需要校验文件

公众平台添加业务域名时，会生成一个**校验文件**（形如 `<随机串>.txt`，内容为平台指定字符串），
要求放在该域名**根目录**可访问（`https://<CUSTOM_DOMAIN>/<校验文件名>` 返回 200 且内容一致）后才允许保存。

**⚠️ 校验文件内容必须由用户从公众平台下载后放入，工程师不能虚构内容**（T02 标注该依赖）。

---

## 2. 校验文件放置（方式 1 推荐：放 `web/public/`）

| 维度 | **方式 1：放 `web/public/`（推荐）** | 方式 2：直接上传静态托管根目录 |
|---|---|---|
| 机制 | 文件放 `web/public/<校验文件名>` → `npm run build` 拷进 `web/dist/` → `tcb hosting deploy web/dist` → 落在托管根目录 | 控制台/CLI 直接 `tcb hosting deploy <校验文件>` 到托管根目录 |
| 进 git / 可复现 | ✅ 版本化、任何环境重建一致 | ❌ 手工一次性动作，不入版本库 |
| 部署耦合 | 随前端发布（校验文件极少变，一次性） | 独立于前端发布 |
| 风险 | 低 | 若托管目录被清空重建（全量覆盖部署）可能丢失，需重传 |
| 适用 | **推荐**：文件生命周期与前端产物一致，天然在根目录 | 备选：不想触发前端重建时 |

> 当前 `web/public/` 已放占位说明 `README-miniapp-verify-file.md`（不入构建产物，仅提示操作步骤）。
> **真实校验文件不要提交 git**（内容为平台一次性生成，属于配置材料而非源码）。

---

## 3. 操作步骤

1. 登录微信公众平台 → 小程序 → **开发管理 → 开发设置 → 业务域名** → 添加 `<CUSTOM_DOMAIN>`
2. **下载平台生成的校验文件**（记下文件名，形如 `<随机串>.txt`）
3. 把校验文件放入 `web/public/<校验文件名>`（方式 1），重建并部署前端：
   ```bash
   cd web && npm run build
   tcb hosting deploy web/dist -e <envId>
   ```
   （或方式 2：直接把校验文件部署到静态托管根目录）
4. 验证校验文件可访问且内容一致：
   ```bash
   curl https://<CUSTOM_DOMAIN>/<校验文件名>
   # 期望返回 200 且内容与公众平台生成的一致
   ```
5. 回到公众平台保存（保存时平台自动回验）
6. 配置生效后：开发者工具 web-view 加载业务域名页面**不再出现「非业务域名」拦截提示**（AC-M3.3）

---

## 4. 常见失败排查

| 现象 | 原因 | 解法 |
|---|---|---|
| 保存时提示校验失败 | 校验文件 404 | 检查文件是否落在**根目录**（不是子路径）；方式 1 确认构建部署完成 |
| 校验文件 404 | 静态托管目录被清空重建 | 方式 2 重传，或改用方式 1 随构建产物部署 |
| HTTPS 无效 | 证书未签发 / 过期 | 回 CloudBase 域名管理检查证书状态，等待签发完成 |
| CNAME 未生效 | DNS 解析未生效/配错 | `dig +short CNAME <CUSTOM_DOMAIN>` 核对解析值 |
| web-view 仍被拦「非业务域名」 | 域名没保存成功 / 开发者工具缓存 | 确认公众平台保存成功；工具详情 → 本地设置检查「不校验合法域名」是否误勾（调试期临时用，配置后应取消） |
| 内容不一致 | 放错文件 / 被篡改 | 重新从公众平台下载，核对文件名与内容 |
