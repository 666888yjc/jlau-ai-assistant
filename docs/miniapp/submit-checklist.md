## 2. 提交流程步骤

1. 开发者工具 → 「上传」→ 填版本号（如 `1.0.0`）与备注 → 公众平台「版本管理」出现开发版
2. 公众平台 → 版本管理 → 开发版 → 「提交审核」
3. 按平台表单填写：类目（§1 第 1 项）、版本说明（§1 第 4 项）、截图（§1 第 6 项）
4. 确认隐私指引已配置（未配置会拦截提交）
5. 提交后进入审核队列；记录提交时间

---

## 3. 审核周期说明 + 加急预案

| 项 | 说明 |
|---|---|
| 普通审核 | 通常 1–7 天（PRD §6 Phase 6 已按 7 天缓冲预留） |
| 计划 | 8/15–8/16 提审 → 8/16–8/23 审核等待 |
| **加急预案** | **若 8/21 仍未过审**：公众平台 → 版本管理 → 对应版本 → 申请加急审核（后台申请，通常 2 小时内出结果）；提前与用户确认加急次数额度 |
| 被驳回 | 按驳回原因修改类目/文案/材料重提，**务必在 8/26（D18）前再次过审**（PRD §6 Phase 6） |

## 4. 发布检查单（AC-M4.5）

提审通过后、正式发布前逐项勾选：

- [ ] 小程序壳真机（iOS + Android）web-view 加载、问答闭环、分享卡片均正常
- [ ] 域名证书有效、`/api/v1/scenarios` 返回 JSON（`scripts/verify-custom-domain.sh` 全绿）
- [ ] 业务域名配置生效、无「非业务域名」拦截
- [ ] 名称/头像/简介/版本说明与 `category-and-copy.md` 定稿一致
- [ ] 隐私指引已配置
- [ ] 线上 H5 回归（默认域名）无回归（保护对象零触碰前提下）
- [ ] 发布后 8/26–8/27 观察期：小程序真机 + 线上 H5 回归
