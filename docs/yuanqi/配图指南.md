# 吉小农 · 配图指南（回答带图）

> 目标：让吉小农在回答新生「衣食住行」问题时带上真实图片（宿舍长啥样、食堂在哪、校门/蓝湖、周边怎么走）。
> 本指南配合 `docs/yuanqi/images-stub/`（占位图）与 `图文知识库样张-占位图.html`（图文文档）使用。

---

| 文件 | 用途 |
|------|------|
| `images-stub/dorm-stub.png` | 宿舍占位图（待替换） |

## 2. 怎么验证「回答带图」机制（零代码，10 分钟）

1. 打开 yuanqi.tencent.com → 进入你的「吉小农」智能体 → 知识库 → 导入文档
2. 选「本地文档导入」→ 上传 `图文知识库样张-占位图.html`
3. 等状态变「已发布」
4. 右侧调试窗口问：**「宿舍长什么样？」「食堂在哪？」「校门和蓝湖怎么走？」**
5. 观察回答是否带出占位图

> ⚠️ 验证预期说明：元器纯知识库问答对「回显图片」的支持程度，取决于其图文渲染策略。
> - 若回答**带出了图** → 机制通，直接替换真图即可（见 §4）。
> - 若回答**只引用了文字没带图** → 说明纯 KB 模式下图回显有限。此时走 **§5 路径 B（公众号智能体模板）** 才是带图正解，占位图阶段也能用该模板发带图推文验证。

---

## 3. 真实图片从哪来（关键红线）

**真实校园图必须由你提供，公网随便抓的图禁止用**：
- ❌ 百度/小红书搜的「吉农宿舍图」——版权不清 + 极可能图不对景（别的学校），会误导新生，比没图还糟。
- ✅ **你自己拍**：你在吉农就读，手机拍宿舍/食堂/校门/蓝湖/图书馆/周边地标最真实、新生最爱看。
- ✅ **学校官方公开图**：学校官网、官方公众号已发布的校园图，可引用（建议标注「图源：吉林农业大学官方」）。

---

## 4. 拿到真图后怎么替换

1. **命名规范**（便于管理，非强制）：
   - `dorm-1.jpg`（宿舍）、`canteen-2.jpg`（食堂）、`gate.jpg`（校门）、`lake.jpg`（蓝湖）、`library.jpg`（图书馆）、`map-bus.jpg`（公交站）
   - 建议：横向图 ≥1280px 宽，单图 <2MB，jpg 即可。
2. 把真图放进 `docs/yuanqi/images-stub/`，覆盖或新增。
3. 二选一生成图文文档：
   - **简单**：直接编辑 `图文知识库样张-占位图.html`，把占位 `<img>` 换成真图 base64（或改成本地相对路径后转 PDF/Word 内嵌）。
   - **重跑脚本**：改 `scripts/gen_stub_images.py` 里 `imgs` 指向真图路径，重跑生成新 HTML。
4. 元器知识库删旧传新（文档增删**即时生效，不用重新发布**）。

> 若元器对 HTML 图文解析不理想，改用 **Word/PDF 内嵌图** 上传（元器对 docx/pdf 图文支持更稳定）：用任意编辑器把图插进文档另存即可。

## 5. 元器带图的两条正经路径（对比）

| 路径 | 做法 | 带图效果 | 适合 |
|------|------|----------|------|
| **A 图文知识库** | 上传图文混排文档（本样张即此思路） | 取决于元器 KB 图文渲染 | 静态图文问答、快速验证 |
| **B 公众号智能体模板** | 你先发 1-2 篇带图推文（我帮你写稿）→ 元器「公众号智能体」一键拉取 | **官方最顺，回答自动带图** | 想稳定带图、且你有公众号 |

**结论**：先按 §2 用占位图验证机制；若 A 路径带图不稳，直接走 B（发带图推文 + 公众号智能体模板），这是元器官方验证过的带图方案。

---

## 6. 安全 / 合规

- 图片不含个人隐私（人脸打码，尤其宿舍内景）。
- 不放入任何账号、密钥、证件号（AC-10）。
- 引用官方图标注来源；自拍图确保你有权发布。
- 高德地图实时图（导航/周边搜索）属 route-B 能力，元器零代码路线不覆盖。

## 7. 高德静态地图出图（真实位置图，已验证可用）

用户对「回答带图」的一个关键提议是：**用高德地图直接截图作为位置类图片**。这个方向完全成立，且已经用你的 key 跑通。但它只适合**「位置/导航/周边」类问题**，不能替代宿舍/食堂内部实拍图。

### 7.1 为什么高德出图可信

| 维度 | 高德静态地图 | 网搜宿舍实拍图 |
|------|--------------|----------------|
| 真实性 | 按真实经纬度渲染，不会图不对景 | 第三方聚合站（haojiao.net / kaodongli.com）自己都写"不保证真实" |
| 版权问题 | 高德 API 出图可在产品中使用（按高德服务条款） | 来源不明，可能侵权 |
| 适用问题 | "食堂在哪""宿舍区怎么走""周边美食在哪" | "宿舍内部长啥样""食堂二楼环境" |

### 7.2 已生成的图

| 文件 | 说明 |
|------|------|
| `images-amap/jlau-campus-precise.png` | 农大校园位置图（中心为第三食堂），标注点周边可见学生公寓 A3-A8/B2-B7、第一/第二运动场、经济管理学院 |
| `图文知识库样张-高德地图.html` | 把上述地图 base64 内嵌 + 宿舍/食堂/地标文字说明，可单文件上传元器 |

### 7.3 技术说明

- 你的高德 key 可调用「静态地图」服务，已生成真实 PNG。
- 该 key 调用「地理编码」服务返回 `30001`（未开通/未授权），所以坐标改用公开 POI 数据（腾讯地图搜到的校内第三食堂坐标 125.410115, 43.809345）+ OpenStreetMap 备用。
- 生成脚本：`scripts/make_amap_html.py`，后续可按同样模式生成「周边美食地图」「交通到达地图」「报到路线图」等。

### 7.4 如何使用

1. 直接把 `图文知识库样张-高德地图.html` 上传到元器知识库。
2. 调试窗口问：「食堂在哪？」「宿舍区怎么走？」「学校运动场在哪？」看回答是否带图。
3. 若纯 KB 模式不便回显图，走 §5 路径 B（公众号智能体模板）为带图正解。

### 7.5 宿舍/食堂内部实拍图怎么办

高德地图是「地图」不是「照片」，它无法生成宿舍内部、食堂档口、教室环境等实拍图。这些仍需：
- ✅ 你自己拍（最推荐）
- ✅ 引用学校官方已发布图片（如团委官网 `tuanwei.jlau.edu.cn/a/zhaoshengjiuye/1003.html` 新生攻略里的宿舍/食堂/蓝湖图）
- ❌ 禁止从搜索引擎/第三方聚合站随便抓图
