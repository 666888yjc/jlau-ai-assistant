# 吉小农 · 腾讯元器操作手册（零代码，绕开 Coze 额度）

> 适用：没有编程基础的同学。全程只在 腾讯元器 网站 + 你的微信公众号后台操作，不碰任何代码、不装软件、不耗 Coze 积分。
> 目标：30 分钟内让「吉小农」在微信公众号里答新生报到问题，且**元器官方渠道 token 免费不限量**。
> 复用文件：本手册直接用 `../route-a/COZE-知识库-整合版.md`（整合知识库）和 `../route-a/COZE-机器人提示词.md`（提示词），无需重做。

## 为什么选元器（解决 Coze 积分不够）
- Coze 国内版按 bot 调用次数扣免费额度，发布到渠道后新生每句对话都扣，几下见底。
- 腾讯元器官方渠道（公众号 / 微信客服 / 企业微信 / 元宝）**token 免费不限量**，等于换一个不限额的免费池。
- 知识库支持上传 `.md` 文件，文档增删**即时生效、不用重新发布**（对应 AC-07 零代码维护）。

## 重要限制（先看）
- 元器是腾讯系平台，**只发微信生态（公众号 / 小程序 / 微信客服 / 企业微信），不支持抖音**。
  - 若抖音是硬需求：保留 Coze 仅发抖音私信（额度另算），或后续走自托管方案（换免费大脑 + 部署）。
  - 微信侧用元器免费搞定，已覆盖绝大多数新生触达。
- 未认证的微信订阅号：较长回答需用户在微信里回复【继续】才能看全。建议公众号做认证，或让答案尽量精简。

## 第 1 步：打开元器并登录
1. 电脑浏览器（推荐 Chrome）打开 https://yuanqi.tencent.com
2. 点右上角「登录」，用**微信扫码**登录（没有就先注册）。

## 第 2 步：创建智能体
1. 点「创建智能体」→ 选「空白创建」（标准模式）。
2. 名称填：**吉小农**
3. 简介填：**吉林农业大学新生报到答疑助手**
4. 头像可上传一张校园图（如校训石），也可先用默认。
5. 点「创建 / 保存」进入编辑页。

> 备选：若你已有内容丰富的公众号，也可选「公众号智能体」，元器会自动拉取你历史文章当知识库；但新生助手内容多来自学校公开信息而非你的推文，故推荐「空白创建 + 上传文档」。

## 第 3 步：粘贴提示词（让它会说话、不乱编）
1. 在「人设 / 提示词」输入框，打开 `../route-a/COZE-机器人提示词.md`，把里面 ``` 代码块里的文字**整段复制**粘贴进来。
2. （可选）粘贴后点输入框旁的「**AI 优化**」按钮，元器会自动把提示词扩写成结构化表达，效果更好；优化后看一眼没删掉「不编造 / 答不出转人工 / 结尾标 AI 生成内容」即可。
3. 点「保存」。

## 第 4 步：上传知识库（让它能答真问题）
1. 左侧导航点「**知识库**」→「**新建知识库**」。
2. 名称填：**吉农新生报到**，描述可写「吉林农业大学新生报到全场景（报到/交通/住宿/缴费/户口/档案/军训/校园卡/食堂/地标/联系方式），来源可溯」。
3. 进入该知识库，点「**新建 / 上传文档**」→「本地文档导入」。
4. 选择 `../route-a/COZE-知识库-整合版.md`（一次传这一个文件即可，已含 11 主题）。
5. 等待状态从「解析中 / 学习中」变为「**已发布**」（正常公开信息可过审；若审核失败按提示改后重传）。
6. 回到智能体编辑页，在「知识 / 上下文」里**添加知识库**，选刚建的「吉农新生报到」，开启知识检索。
   - 建议开启「**外部引用链接**」：回答末尾会展示来源，正好用上我们素材里的来源标注。

## 第 5 步：先自己测一下（上线前必做）
在右侧「预览调试」面板依次问这几句，看回答对不对：
- 「报到要带啥？」
- 「我从长春站怎么去学校？」
- 「计算机专业学费多少？」
- 「宿舍能洗澡吗？」
- 「保研率多少？」（应回答"不太确定，建议联系招生办 0431-84532980"，**不能瞎编**）
- 「今天天气怎么样？」（应引导回报到相关或说明只答报到问题）

> 回答不对：检查第 4 步知识库是否关联上、状态是否「已发布」；或回到第 3 步微调提示词。调试面板会显示耗时和 token 消耗，官方渠道免费。

## 第 6 步：发布到微信公众号
1. 编辑页点右上角「**发布**」。
2. 发布渠道选「**微信订阅号**」（个人主体用订阅号；服务号亦可）。
3. 用**公众号管理员**微信扫码授权（首次授权会加入发布渠道）。
4. 提交审核，通常几分钟通过；通过后粉丝在公众号对话框发消息就能和「吉小农」对话。
5. （可选）把智能体挂到菜单：审核通过后复制智能体网址 → 登录公众号后台「内容与互动 → 自定义菜单」→ 新建菜单选「跳转网页」→ 粘贴网址。粉丝点菜单即进对话页。

> 提示：未认证订阅号长回答需用户回【继续】才显示全。要么给公众号做认证，要么把答案写精简（提示词已要求"一次说清要点"）。

## 第 7 步：上线后维护（零代码）
- **拿到学校《2026 新生入学须知》PDF 后**：在元器知识库里把对应主题文档**删除旧版、上传新版**即可，**不用重新发布**（元器知识增删即时生效）。
- 发现新生常问但答不上来的问题：把答案补进知识库文档再重传。

## 常见问题
- **问：要花钱吗？** 元器官方渠道（公众号等）token 免费不限量；仅第三方平台接入有每月 100 万 token 免费额度。基本零成本。
- **问：能发抖音吗？** 不能，元器只发微信生态。抖音需另走 Coze（额度另算）或自托管。
- **问：文档审核要多久？** 一般几分钟到十几分钟；公开信息（报到/交通等）通常直接过。
- **问：答错了怎么办？** 调试里多问几轮校准提示词；或把正确信息补进知识库重传。

完成第 6 步，吉小农就在公众号里免费上线了，新生随便问都不扣你额度。
