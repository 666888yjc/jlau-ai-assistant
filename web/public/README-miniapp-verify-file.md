# 微信公众平台业务域名校验文件放置说明（占位）

本目录（`web/public/`）用于放置微信公众平台「业务域名」配置时生成的**校验文件**。

## 操作流程（详见 docs/miniapp/business-domain.md）

1. 登录微信公众平台 → 小程序 → 开发管理 → 开发设置 → 业务域名 → 添加 `<CUSTOM_DOMAIN>`
2. **下载平台生成的校验文件**（形如 `<随机串>.txt`，内容由平台生成）
3. 把该校验文件放入本目录（文件名保持平台给的原名）
4. 重建并部署前端（`cd web && npm run build` + `tcb hosting deploy web/dist -e <envId>`）
5. `curl https://<CUSTOM_DOMAIN>/<校验文件名>` 返回 200 且内容一致
6. 回到公众平台保存（平台自动回验）

## ⚠️ 重要

- **校验文件内容必须由用户从公众平台下载后放入，不能虚构**——本仓库不提交真实校验文件（一次性配置材料，不入 git）。
- 本 README 仅为操作提示占位，会随构建进入 dist 根目录，属无害文档文件，可随时删除。
- 添加完成后，可删除本 README 与校验文件（业务域名配置已保存，不再需要根目录文件）。
